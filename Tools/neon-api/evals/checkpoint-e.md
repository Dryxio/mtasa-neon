Evaluator: independent `gpt-5.6-sol` agent, no conversation context

Workspace: disposable `/tmp/neon-checkpoint-e.SWeuKb`; repository read-only

## Scope

The evaluator discovered the CLI from its own help and documentation, authored
a disposable client/server project with a typed resource contract, exercised
intent-based MTA and Neon API discovery, corrected deliberate project errors,
generated two independent agent context packs, and verified their content,
side isolation, determinism, and tamper resistance.

An earlier independent discovery audit rejected the first candidate because it
missed common intent vocabulary and produced imprecise rankings. Its cases are
now closed regressions covering HTTP requests, timers, ambient traffic,
American and British tyre spelling, destructible objects, replay, raycasts,
natural client/server wording, and the former `backfire`/`back` false positive.

## Discovery gate

The evaluator independently found upstream APIs, a sparse runtime-only Neon
function, and a conflicting event from vague task descriptions. Exact retrieval
of `setPedNavigateTo` retained variadic `unknown` parameters and an `unknown`
return rather than inventing a signature.

Compact search and explicit `--full` returned the same matches while reducing
one representative result from 12,145 bytes to 826 bytes. Repeated searches
were byte-identical. The generated index contained 2,335 profile-filtered
symbols and deterministic discovery keywords.

## Context and isolation gate

Two fresh context packs generated by separate CLI processes were byte-for-byte
identical and both passed `context verify`. LuaLS separation was checked for
global APIs, runtime OOP classes, project exports, custom events, and the exact
libraries named by each `.luarc.json`.

Tampering a copied `server/project-server.lua` changed its hash and caused
`CONTEXT_ARTIFACT_HASH_MISMATCH`; the untouched original continued to verify.
